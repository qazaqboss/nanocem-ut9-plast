# NanoCem UT-9 в пласте

Анимация применения NanoCem UT-9 для водоизоляции — снижает обводнённость и повышает дебит нефти: две проблемы с водой → затворение → закачка по НКТ → проникновение → ОЗЦ → разбуривание и опрессовка → перфорация выше экрана → чистая нефть.

Один файл без зависимостей — `index.html`, открывается в любом браузере.

- Управление: ← / → — этапы, пробел — пауза, клик по разрезу — на весь экран.
- Скорость: `index.html?speed=1` — реальный сценарий 49 с; `?speed=0.4` — ~2 мин для записи видео. Без параметра — 22 с.

Сценарий видео с озвучкой — [SCENARIO.md](SCENARIO.md).

Сайт: https://nanocem.vercel.app/#reservoir
